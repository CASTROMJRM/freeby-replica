# Freeby Réplica — Índice

Réplica de [freeby.mx](https://freeby.mx/) con WordPress + WooCommerce, hecha con IA (Claude Code) y documentada en Obsidian.
Reto asignado por César durante la estadía.

## Objetivo
- Replicar estilo, diseño y contenido de freeby.mx.
- Tienda con WooCommerce.
- Documentar todo el proceso para que otra persona (o una IA) pueda continuar sin empezar de cero.
